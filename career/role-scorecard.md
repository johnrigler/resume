# Role scorecard

Use this checklist for each posting. Record **unknown**, not assumptions.

| Criterion | Desired | Hard stop? |
|---|---|---|
| Remote eligibility | Explicitly hires New Mexico residents | Yes if NM excluded |
| Travel | 0–2 onsite trips per year | Discuss if greater |
| Work | Enterprise technical support / systems / cloud / API troubleshooting | No |
| Employment | W-2 preferred; full-time or suitable part-time | No |
| Pay | Competitive with technical experience; evaluate base separately from bonuses | No |
| On-call | Confirm frequency, hours, compensation and escalation model | Unknown |
| Tooling | Linux, networks, cloud, automation, JS, REST, security | No |
| Employer | Verifiable identity and official application path | Yes if unverifiable |

Score each as **strong fit**, **possible**, or **skip**. Note missing facts and a single next action.
